Browser Extension Privacy Policy

For the StayAwake browser extension · Last updated: October 28, 2026

StayAwake is a browser extension developed by Pranav Arya. Its purpose is to help prevent your device's display from turning off due to inactivity while the keep-awake feature is enabled. This policy applies to the browser extension available through the Chrome Web Store and compatible Chromium-based browsers.

The separate StayAwake web application has its own privacy policy.

1. Information stored locally

The extension stores a preference indicating whether its keep-awake feature is enabled or disabled. This preference is stored under the isActive key using Chrome's chrome.storage.local API. It is used to restore the popup's toggle state and update the extension icon.

This preference is stored locally in the browser. The extension's code does not transmit the saved ON/OFF preference to a StayAwake-operated server.

2. Permissions

Power: The extension uses Chrome's Power API to request that the device display remain awake while the feature is enabled. When the user disables the feature, the extension releases the keep-awake request.

Storage: The extension uses local extension storage to save and retrieve the enabled or disabled preference.

3. Google Fonts and external requests

The current extension popup references Google Fonts to load the Poppins typeface. When the popup loads the font stylesheet and font files, the browser sends requests to Google's font infrastructure. Google necessarily receives the requesting IP address to deliver the resources and may process other technical request information under its own policies.

The extension does not use Google Fonts to send the saved ON/OFF preference to Google. For further information, review Google's Privacy Policy and Google Fonts' privacy information.

The popup also contains a link to the developer's website. If you click that link, your browser navigates to the external site, which operates under its own privacy practices.

4. Information the extension does not collect through its own features

The extension's inspected application logic does not include functionality intended to collect or transmit browsing history, webpage content, passwords, financial information, health information, personal communications, location data, keystrokes, mouse movements, or general browsing activity. It does not provide user accounts, cloud synchronization, or a developer-operated database.

The extension's saved application preference is the enabled or disabled state described above. External font requests are described separately in Section 3.

5. Data sharing

StayAwake does not sell the locally stored preference or send it to advertising networks or data brokers. The extension code does not send the preference to the developer's servers. Google receives technical request information when the popup loads Google Fonts, as described in this policy, and handles that request information under its own policies.

6. Data retention and deletion

The enabled or disabled preference remains in the browser's local extension storage until it is changed or the stored data is removed. You can remove the extension through your browser's extension management page. The browser manages removal of the extension and its associated storage.

7. Security

StayAwake is designed to keep its application preference locally in the browser. It does not transmit that preference to a StayAwake-operated server. Keep your browser and extensions up to date and install the extension only from a trusted source.

8. Changes to this policy

This policy may be updated if the extension's functionality, permissions, external resources, or data practices change. The latest version and revision date will be published at this URL.

9. Contact

For questions or privacy concerns about the extension, please open an issue in the StayAwake GitHub repository. Please do not post sensitive personal information in a public issue.
